
# Automated File Organizer

## Project Description
This Python project automatically organizes files into folders
based on their file extensions.

## Features
- Automatically sorts files into folders.
- Supports documents, images, videos, and audio files.
- Creates folders if they do not exist.
- Places unknown file types into an Others folder.
- Skips duplicate filenames to avoid overwriting files.
- Displays the number of files moved.

## Technologies Used
- Python 3
- os module
- shutil module

## How to Run
1. Install Python 3.
2. Open the project in PyCharm.
3. Run file_organizer.py.
4. Enter the folder path when prompted.
5. Check the organized folders.

## Example Output
